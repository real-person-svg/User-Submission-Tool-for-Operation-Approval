# 功能清单

> 当前阶段：仅创建项目。以下业务功能均为规划，尚未实现；复选框仅表示实际完成状态。

## 1. 已完成的工程基础

- [x] Vue 3 + TypeScript 前端入口。
- [x] Vite 开发服务与 API 代理配置。
- [x] Element Plus 接入及占位页面。
- [x] Node.js + TypeScript + Fastify 后端入口。
- [x] 健康检查接口 `GET /api/health`。
- [x] SQLite 连接函数预留，不自动创建业务数据。
- [x] 前后端共享业务类型预设。
- [x] 类型检查、开发启动、构建和生产启动命令。
- [x] README 与提交说明文档。

## 2. 投稿列表（待实现）

- [ ] 展示标题、作者、内容摘要、分类、提交时间和审核状态。
- [ ] 默认显示待审核投稿。
- [ ] 按状态、关键词和提交时间筛选。
- [ ] 服务端分页与总数展示。
- [ ] 加载中、空列表、查询失败及重试提示。

## 3. 投稿详情（待实现）

- [ ] 使用抽屉展示完整投稿。
- [ ] 展示审核人、审核时间和驳回原因。
- [ ] 展示该投稿的历史审核日志。

## 4. 单条审核（待实现）

- [ ] 通过待审核投稿。
- [ ] 驳回待审核投稿，原因必填且不能只有空格。
- [ ] 操作前明确展示审核对象和动作。
- [ ] 提交期间禁用重复操作，成功后刷新列表。

## 5. 批量审核（待实现）

- [ ] 勾选当前页的多条待审核投稿。
- [ ] 显示已选数量，支持清空选择。
- [ ] 分页或切换筛选条件时清空选择。
- [ ] 批量通过、使用统一原因批量驳回。
- [ ] 不同驳回原因的投稿分批或单独处理。
- [ ] 返回每条投稿的处理结果。
- [ ] 显示成功数量、失败数量和失败原因。

## 6. 操作人与日志（待实现）

- [ ] 从预置人员中选择当前操作人。
- [ ] 未选择操作人时阻止审核。
- [ ] 保存操作人、操作时间、审核动作和原因。
- [ ] 用批次 ID 关联同一次批量审核产生的记录。
- [ ] 支持按投稿或操作人查询审核日志。

## 7. 数据与一致性（待实现）

- [ ] 创建投稿表、操作人表和审核日志表。
- [ ] 提供初始化与演示数据脚本。
- [ ] 约定状态为待审核、已通过、已驳回。
- [ ] 仅允许待审核状态转为已通过或已驳回。
- [ ] 根据状态和版本号执行条件更新，防止重复审核。
- [ ] 批量审核允许业务层面部分成功，逐条返回状态冲突。
- [ ] 状态更新与日志写入处于同一事务。
- [ ] 数据库异常时回滚整个批次，不保留不完整更新。
- [ ] 参数化查询、外键约束、索引与接口参数校验。

## 8. 易用性与验证（待实现）

- [ ] 提供简短的首次使用说明。
- [ ] 支持窄屏布局和基本键盘操作。
- [ ] 测试驳回原因校验、重复审核、并发冲突和混合批次。
- [ ] 测试日志写入失败时事务回滚。
- [ ] 验证从选择操作人到查看审核结果的完整流程。

## 9. 接口规划（均未实现）

- `GET /api/operators`：操作人列表。
- `GET /api/submissions`：筛选、分页查询投稿。
- `GET /api/submissions/:id`：投稿详情。
- `POST /api/reviews`：单条或批量审核。
- `GET /api/review-logs`：查询审核记录。

## 10. 范围约定

- 不实现完整账号系统，操作人选择仅用于演示归属。
- 第一版不提供撤销审核、重新送审或通知功能。
- 题目没有明确的规则以本文件约定为准；正式开发前可以调整。
